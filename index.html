📱 HP vs 💻 PC/Laptop

📱 Kalau pakai HP Android

  • Browser: Chrome atau browser lain.
  • Editor: editor kode Android.
  • Untuk terminal: Termux.
  • Server lokal: python -m http.server 8080.
  • Git/GitHub bisa dikerjakan lewat Termux.
  • Keyboard + mouse OTG boleh dipakai, tapi tidak wajib.
pkg update
pkg install python git
mkdir website
cd website
python -m http.server 8080

💻 Kalau pakai PC/Laptop

  • Browser: Chrome/Firefox/Edge.
  • Editor: VS Code atau editor lain.
  • Terminal: CMD, PowerShell, Terminal Linux/macOS.
  • Git untuk version control.
  • DevTools browser untuk debugging.
  • Node.js/npm berguna saat masuk tooling modern.
mkdir website
cd website
code .
python -m http.server 8080

Penting: HTML, CSS, dan JavaScript yang dipelajari pada dasarnya sama di HP maupun PC. Yang berbeda terutama alat, terminal, editor, dan cara menjalankannya.

BAB 1

🧱 HTML — Fondasi Website

HTML menentukan struktur dan isi halaman. Anggap saja HTML sebagai kerangka rumah.

1. Struktur dokumen HTML

Dokumen HTML biasanya dimulai dengan deklarasi HTML, lalu html, head, dan body.

<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <title>Website Saya</title>
</head>
<body>
  <h1>Halo!</h1>
</body>
</html>
Latihan: Ganti judul tab dan tulisan Halo!.
2. Heading dan paragraph 
<h1>Judul Utama</h1>
<h2>Subjudul</h2>
<p>Ini sebuah paragraf.</p>

h1 sampai h6 digunakan untuk tingkatan heading. p untuk paragraf.

3. Link dan gambar 
<a href="https://example.com">Buka website</a>

<img src="gambar.jpg" alt="Deskripsi gambar">

href menentukan tujuan link. src menentukan sumber gambar. alt membantu aksesibilitas.

4. List 
<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>

<ol>
  <li>Pertama</li>
  <li>Kedua</li>
</ol>
5. Button 
<button>Klik Saya</button>

Button sendiri belum otomatis melakukan aksi. Nanti JavaScript yang membuatnya interaktif.

6. Table 
<table>
  <tr><th>Nama</th><th>Nilai</th></tr>
  <tr><td>Budi</td><td>90</td></tr>
</table>
7. Form dan input 
<form>
  <label>Nama:</label>
  <input type="text" placeholder="Nama kamu">
  <button type="submit">Kirim</button>
</form>
8. div, span, class, id 
<div class="kartu">
  <h2 id="judul">Halo</h2>
  <span>Teks kecil</span>
</div>

class cocok untuk banyak elemen. id biasanya digunakan untuk satu elemen tertentu.

9. Semantic HTML 
<header>Header</header>
<nav>Menu</nav>
<main>Isi utama</main>
<section>Bagian</section>
<article>Artikel</article>
<footer>Footer</footer>

Elemen semantik membantu struktur halaman lebih jelas.

10. Media dan metadata 
<audio controls src="musik.mp3"></audio>
<video controls src="video.mp4"></video>

<meta name="description" content="Website belajar coding">

🎯 Project HTML

BAB 2

🎨 CSS — Membuat Website Bagus

CSS mengatur warna, ukuran, jarak, posisi, layout, responsif, dan animasi.

1. Memasang CSS 
<style>
  body { background: lightblue; }
  h1 { color: blue; }
</style>

Untuk project besar, CSS biasanya dipisahkan menjadi style.css lalu dipanggil dengan <link>.

2. Selector 
p { color: red; }
.kartu { padding: 20px; }
#judul { font-size: 40px; }
3. Warna, background, font, text 
body {
  background: #f4f7fb;
  color: #172033;
  font-family: Arial, sans-serif;
}
h1 {
  color: #4f7cff;
  text-align: center;
  font-size: 48px;
}
4. Box model: margin dan padding 
.kotak {
  margin: 20px;
  padding: 20px;
  border: 2px solid black;
  width: 250px;
}

Padding adalah ruang di dalam elemen. Margin adalah ruang di luar elemen.

5. Border, radius, shadow 
.kartu {
  border: 1px solid #ddd;
  border-radius: 15px;
  box-shadow: 0 5px 20px #0002;
}
6. Flexbox 
.container {
  display: flex;
  justify-content: center;
  align-items: center;
  gap: 15px;
}

Flexbox sangat berguna untuk menyusun elemen secara horizontal atau vertikal.

7. Grid 
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 15px;
}
8. Position dan z-index 
.kotak {
  position: relative;
  top: 10px;
}

.menu {
  position: fixed;
  top: 0;
  z-index: 100;
}
9. Pseudo-class dan pseudo-element 
button:hover {
  transform: scale(1.05);
}

p::first-letter {
  font-size: 30px;
}
10. Transition dan animation 
button {
  transition: .2s;
}
button:hover {
  transform: scale(1.05);
}

@keyframes muncul {
  from { opacity: 0; }
  to { opacity: 1; }
}

.kartu {
  animation: muncul 1s;
}
11. Responsive / media query 
@media (max-width: 600px) {
  h1 { font-size: 30px; }
  .container { grid-template-columns: 1fr; }
}

Dengan media query, tampilan dapat menyesuaikan layar HP, tablet, dan PC.

12. CSS variables 
:root {
  --utama: #4f7cff;
}

button {
  background: var(--utama);
}

🎯 Project CSS

Ambil project HTML sebelumnya lalu ubah menjadi website profil yang punya kartu, tombol, layout Flexbox/Grid, animasi, dan tampilan HP.

BAB 3

⚙️ JavaScript — Otak Website

1. Variabel 
let nama = "Budi";
const umur = 15;

console.log(nama);
console.log(umur);

let dapat diubah. const digunakan untuk nilai yang tidak perlu diganti.

2. String, number, boolean 
let nama = "Budi";
let umur = 15;
let aktif = true;
3. Operator 
let a = 10;
let b = 3;

console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);
console.log(a > b);
4. If / else 
let nilai = 80;

if (nilai >= 75) {
  console.log("Lulus");
} else {
  console.log("Belum lulus");
}
5. Loop 
for (let i = 1; i <= 5; i++) {
  console.log(i);
}

let x = 0;
while (x < 5) {
  console.log(x);
  x++;
}
6. Function 
function sapa(nama) {
  return "Halo " + nama;
}

console.log(sapa("Budi"));
7. Array 
let buah = ["Apel", "Jeruk", "Mangga"];

console.log(buah[0]);
buah.push("Pisang");
8. Object 
let player = {
  nama: "Alex",
  level: 5,
  koin: 100
};

console.log(player.nama);
9. Function modern / arrow 
const tambah = (a, b) => {
  return a + b;
};
10. Template literal 
let nama = "Budi";
let umur = 15;

console.log(`Nama saya ${nama}, umur ${umur}`);

🎯 Project JavaScript dasar

Buat program penghitung nilai: pengguna memasukkan nilai, JavaScript menentukan kategori nilai dan menampilkan hasil.

BAB 4

🖱️ DOM & Interaksi

DOM memungkinkan JavaScript membaca dan mengubah elemen HTML.

1. Mengambil elemen 
const judul = document.getElementById("judul");
const tombol = document.querySelector(".tombol");
2. Mengubah teks 
judul.innerText = "Judul Baru!";
3. Mengubah CSS 
judul.style.color = "red";
judul.style.fontSize = "50px";
4. Event click 
tombol.addEventListener("click", () => {
  judul.innerText = "Tombol ditekan!";
});
5. Input 
const input = document.querySelector("#nama");
const hasil = document.querySelector("#hasil");

function tampilkan() {
  hasil.innerText = input.value;
}
6. Membuat elemen dengan JS 
const p = document.createElement("p");
p.innerText = "Elemen baru!";
document.body.appendChild(p);
7. Mini quiz 
let jawaban = "html";

if (jawaban === "html") {
  console.log("Benar!");
} else {
  console.log("Salah!");
}

🎯 Project DOM

Buat to-do list sederhana: input tugas → klik tambah → tugas muncul di halaman → tombol hapus menghapus tugas.

BAB 5

🧠 JavaScript Lanjutan

1. Array methods 
const angka = [1, 2, 3, 4];

const kaliDua = angka.map(x => x * 2);
const besar = angka.filter(x => x > 2);

console.log(kaliDua);
console.log(besar);
2. Destructuring & spread 
const user = { nama: "Budi", level: 5 };
const { nama, level } = user;

const a = [1, 2];
const b = [...a, 3, 4];
3. LocalStorage 
localStorage.setItem("nama", "Budi");

const nama = localStorage.getItem("nama");
console.log(nama);

Bisa digunakan untuk menyimpan data sederhana di browser.

4. JSON 
const data = {
  nama: "Budi",
  level: 5
};

const teks = JSON.stringify(data);
const kembali = JSON.parse(teks);
5. Timer 
setTimeout(() => {
  console.log("Jalan setelah 2 detik");
}, 2000);

setInterval(() => {
  console.log("Berulang");
}, 1000);
6. Promise dan async/await 
async function mulai() {
  const hasil = await Promise.resolve("Berhasil!");
  console.log(hasil);
}

mulai();
7. Error handling 
try {
  throw new Error("Contoh error");
} catch (error) {
  console.log(error.message);
}
BAB 6

📱 Responsive Web Design

Website harus nyaman dilihat di layar kecil maupun besar.

HP
Layout satu kolom, tombol mudah disentuh, teks tidak terlalu kecil.
Tablet
Gunakan ruang layar dengan lebih fleksibel.
PC/Laptop
Manfaatkan layout lebar tanpa membuat teks terlalu panjang.
@media (max-width: 700px) {
  .grid {
    grid-template-columns: 1fr;
  }
}
BAB 7

🌐 JSON & API

API memungkinkan website mengambil atau mengirim data ke layanan lain.

async function ambilData() {
  try {
    const response = await fetch("https://example.com/data.json");
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.log("Gagal:", error);
  }
}

ambilData();
Catatan: API asli bisa membutuhkan URL tertentu, parameter, autentikasi, atau API key. Jangan menaruh secret key penting langsung di JavaScript frontend.
BAB 8

🛠️ Debugging

Program error itu normal. Yang penting tahu cara mencari penyebabnya.

  • Buka Console DevTools.
  • Baca pesan error dan nomor baris.
  • Gunakan console.log().
  • Periksa nama variabel dan tanda kurung.
  • Uji kode sedikit demi sedikit.
console.log("Sampai sini");

let angka = 10;
console.log("angka =", angka);
BAB 9

♿ Aksesibilitas & Struktur

  • Gunakan heading secara terstruktur.
  • Berikan alt yang bermakna pada gambar.
  • Gunakan label untuk input.
  • Pastikan tombol bisa dibaca dan digunakan.
  • Jangan hanya mengandalkan warna untuk menyampaikan informasi.
BAB 10

🔐 Keamanan Dasar Web

  • Jangan membocorkan API key/secret ke publik.
  • Validasi data dari pengguna.
  • Jangan asal memasukkan input pengguna ke HTML menggunakan innerHTML.
  • Untuk aplikasi nyata, keamanan backend juga diperlukan.
