🐧 Cara Menggunakan GNU Nano & Neovim

Text editor di dalam terminal tanpa perlu menyentuh mouse!

📝 1. GNU Nano

Cocok untuk pemula. Cara buka: nano index.html

TombolFungsi
Ctrl + OSimpan file (Save / WriteOut)
Ctrl + XKeluar dari Nano (Exit)
Ctrl + KHapus satu baris (Cut)

⚡ 2. Neovim (Nvim)

Editor legendaris dengan 3 mode sakti:

  • Tekan i untuk masuk Insert Mode (Mengetik kode).
  • Tekan Esc untuk kembali ke Normal Mode (Navigasi).
  • Ketik :wq di Normal Mode untuk Simpan & Keluar.
