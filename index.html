Selamat Datang!

Website ini dibuat untuk belajar dasar-dasar pemrograman dengan cara yang sederhana dan mudah dipahami.

1. Apa itu HTML?

HTML adalah bahasa yang digunakan untuk membuat struktur sebuah halaman web.

Contoh: 
<h1>Halo Dunia!</h1>
<p>Ini website pertama saya.</p>

<h1> digunakan untuk judul utama, sedangkan <p> digunakan untuk paragraf.

2. Apa itu CSS?

CSS digunakan untuk mengatur tampilan website, seperti warna, ukuran tulisan, posisi, dan bentuk tombol. 

h1 {
    color: blue;
    text-align: center;
}

Dengan CSS, website yang awalnya polos bisa dibuat jauh lebih menarik.

3. Apa itu JavaScript?

JavaScript digunakan untuk membuat website menjadi interaktif. 

function halo() {
    alert("Halo!");
}

Contohnya, JavaScript bisa membuat tombol melakukan sesuatu ketika ditekan.

4. Gabungkan semuanya

HTML, CSS, dan JavaScript biasanya bekerja bersama:

🧱 HTML = struktur

🎨 CSS = tampilan

⚡ JavaScript = interaksi

<h1>Website Saya</h1>

<button onclick="halo()">
    Klik Saya
</button>

<script>
function halo() {
    alert("Berhasil!");
}
</script>

🚀 Langkah Berikutnya

Setelah memahami HTML, CSS, dan JavaScript, kamu bisa mulai membuat website sendiri.

Mulai dari website sederhana, lalu perlahan tambahkan tombol, animasi, game, dan fitur lainnya.
