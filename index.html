BAB 1 — HTML Dasar

Target: memahami struktur halaman web dan mampu membuat halaman HTML sendiri.

1. Apa itu HTML?

HTML adalah bahasa markup untuk menyusun struktur halaman web. HTML memberi tahu browser bagian mana yang merupakan judul, paragraf, gambar, link, tombol, dan sebagainya.

<h1>Halo Dunia!</h1>
<p>Saya sedang belajar HTML.</p>

2. Struktur dokumen HTML

Dokumen HTML biasanya memiliki html, head, dan body.

<!DOCTYPE html>
<html>
<head>
    <title>Website Saya</title>
</head>
<body>
    <h1>Halo!</h1>
</body>
</html>
Bagian body berisi hal yang terlihat di halaman.

3. Heading dan paragraf

<h1>Judul Besar</h1>
<h2>Subjudul</h2>
<h3>Judul Kecil</h3>
<p>Ini sebuah paragraf.</p>

h1 sampai h6 adalah heading dengan tingkat berbeda.

4. Link

<a href="https://example.com">
    Buka Website
</a>

Atribut href menentukan tujuan link.

5. Gambar

<img src="gambar.jpg" alt="Gambar saya">

src menentukan lokasi gambar dan alt memberi deskripsi gambar.

6. List

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

ul membuat daftar dan li membuat item daftar.

7. Button

<button>Klik Saya</button>

Button bisa diberi CSS dan JavaScript agar lebih berguna.

8. Tabel

<table>
    <tr>
        <th>Nama</th>
        <th>Level</th>
    </tr>
    <tr>
        <td>Budi</td>
        <td>Pemula</td>
    </tr>
</table>

9. Form dan input

<form>
    <input type="text" placeholder="Nama">
    <input type="email" placeholder="Email">
    <button>Kirim</button>
</form>

Form digunakan untuk menerima input dari pengguna.

10. Semantic HTML

Elemen seperti header, nav, main, section, dan footer membantu memberi arti pada struktur halaman.

Project BAB 1: Buat halaman profil sederhana menggunakan judul, paragraf, gambar, link, list, dan button.

BAB 2 — CSS Dasar sampai Layout

Target: membuat website terlihat rapi, responsif, dan menarik.

1. Apa itu CSS?

CSS mengatur tampilan HTML: warna, ukuran, jarak, posisi, bentuk, dan banyak lagi.

h1 {
    color: blue;
    font-size: 40px;
}

2. Selector

p {
    color: red;
}

.judul {
    color: blue;
}

#utama {
    color: green;
}

p memilih tag, .judul memilih class, dan #utama memilih id.

3. Warna dan background

body {
    background: #eef9ff;
    color: #222;
}

4. Font dan teks

p {
    font-size: 20px;
    font-weight: bold;
    text-align: center;
}

5. Margin dan padding

.kotak {
    margin: 20px;
    padding: 20px;
}

Margin adalah jarak di luar elemen. Padding adalah jarak di dalam elemen.

6. Border dan radius

.kotak {
    border: 2px solid blue;
    border-radius: 15px;
}

7. Width dan height

.kotak {
    width: 300px;
    height: 150px;
}

8. Flexbox

.menu {
    display: flex;
    justify-content: center;
    gap: 10px;
}

Flexbox sangat berguna untuk menyusun elemen dalam baris atau kolom.

9. Grid

.grid {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: 15px;
}

10. Position

.kotak {
    position: relative;
}

.tombol {
    position: absolute;
    right: 10px;
    top: 10px;
}

11. Responsive

@media (max-width: 600px) {
    h1 {
        font-size: 30px;
    }
}

Media query membuat tampilan bisa menyesuaikan layar HP, tablet, dan perangkat lain.

12. Animasi sederhana

@keyframes muncul {
    from { opacity: 0; }
    to { opacity: 1; }
}

.box {
    animation: muncul 1s;
}
Project BAB 2: Percantik project HTML sebelumnya. Gunakan card, warna, Flexbox, responsive, dan animasi.

BAB 3 — JavaScript Dasar

Target: membuat website bisa merespons tindakan pengguna.

1. Apa itu JavaScript?

JavaScript adalah bahasa pemrograman yang dapat membuat halaman web menjadi interaktif.

<script>
alert("Halo!");
</script>

2. Console

console.log("Halo dari JavaScript");

Console berguna untuk melihat hasil dan membantu mencari masalah dalam program.

3. Variabel

let nama = "Budi";
let umur = 15;

console.log(nama);
console.log(umur);

4. String dan angka

let nama = "Budi";
let umur = 15;

let hasil = umur + 5;

String adalah teks. Angka digunakan untuk operasi matematika.

5. Operator

let a = 10;
let b = 5;

console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);

6. If dan else

let umur = 15;

if (umur >= 17) {
    console.log("Sudah 17 atau lebih");
} else {
    console.log("Masih di bawah 17");
}

7. Loop for

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

Loop menjalankan kode berulang kali.

8. Loop while

let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}

9. Function

function sapa(nama) {
    return "Halo " + nama;
}

console.log(sapa("Budi"));

10. Array

let buah = ["Apel", "Mangga", "Jeruk"];

console.log(buah[0]);

Array menyimpan beberapa nilai dalam satu variabel.

11. Object

let pemain = {
    nama: "Budi",
    level: 5,
    koin: 100
};

console.log(pemain.nama);

12. Event

<button onclick="sapa()">
    Klik
</button>

<script>
function sapa() {
    alert("Tombol ditekan!");
}
</script>

13. DOM

document.getElementById("judul").innerText =
    "Judul berubah!";

DOM memungkinkan JavaScript membaca dan mengubah elemen HTML.

14. Input pengguna

let nama = document.getElementById("nama").value;
console.log(nama);
🧠 Mini Quiz

Apa fungsi document.getElementById()?

Project BAB 3: Buat kalkulator sederhana yang menerima dua angka dan menampilkan hasilnya.

BAB 4 — JavaScript Lanjutan

Target: mulai membuat aplikasi web yang menyimpan data dan mengambil data dari internet.

1. Array Methods

let angka = [1, 2, 3, 4, 5];

let hasil = angka.map(function(x) {
    return x * 2;
});

Method seperti map, filter, dan find membantu mengolah array.

2. Object lebih dalam

let player = {
    nama: "Alex",
    stats: {
        level: 10,
        hp: 100
    }
};

console.log(player.stats.level);

3. addEventListener

button.addEventListener("click", function() {
    console.log("Diklik!");
});

Ini adalah cara umum memasang event tanpa menulis event langsung di HTML.

4. Local Storage

localStorage.setItem("nama", "Budi");

let nama = localStorage.getItem("nama");

Local Storage dapat menyimpan data sederhana di browser.

5. JSON

let data = {
    nama: "Budi",
    level: 10
};

let teks = JSON.stringify(data);
let kembali = JSON.parse(teks);

6. Timer

setTimeout(function() {
    console.log("Selesai");
}, 2000);

7. Fetch dan API

fetch("https://example.com/data")
    .then(response => response.json())
    .then(data => {
        console.log(data);
    });
API nyata membutuhkan alamat endpoint yang benar dan terkadang membutuhkan API key.

8. Async / Await

async function ambilData() {
    const response = await fetch("URL_API");
    const data = await response.json();
    console.log(data);
}

9. Error Handling

try {
    // kode yang mungkin error
} catch (error) {
    console.log(error);
}
Project BAB 4: Buat aplikasi catatan sederhana yang menyimpan catatan menggunakan Local Storage.

BAB 5 — Membuat Website Nyata

Target: menggabungkan semua kemampuan menjadi project yang benar-benar bisa dipakai.

1. Struktur project

website/
├── index.html
├── style.css
└── script.js

Untuk project yang lebih besar, HTML, CSS, dan JavaScript sebaiknya dipisahkan.

2. Multi halaman

<a href="tentang.html">
    Tentang
</a>

Kamu dapat membuat beberapa halaman dan menghubungkannya dengan link.

3. Navigasi

Buat menu yang mengarah ke Home, Tentang, Tutorial, dan Kontak.

4. Responsive mobile

Pastikan ukuran teks, tombol, gambar, dan layout nyaman digunakan di HP.

5. Form

Tambahkan form dan validasi JavaScript agar input pengguna diperiksa sebelum diproses.

6. Data dan API

Gunakan Fetch untuk mengambil data dari API dan tampilkan hasilnya di halaman.

7. Git dan GitHub

Git menyimpan riwayat perubahan project. GitHub dapat digunakan untuk menyimpan kode secara online.

git add .
git commit -m "update website"
git push

8. GitHub Pages

GitHub Pages dapat digunakan untuk menerbitkan website statis sehingga bisa dibuka melalui link.
